Artificial Intelligence is a branch of computer science focused on building systems that can perform tasks that normally require human intelligence. These tasks include understanding language, recognizing images, making decisions, solving problems, and generating content. Modern artificial intelligence systems often rely on machine learning, where computers learn patterns from large amounts of data instead of developers explicitly programming every possible rule. Machine learning itself contains several approaches, including supervised learning, unsupervised learning, and reinforcement learning.

Large Language Models are machine learning models designed to understand and generate human language. They are trained on large collections of text and learn statistical relationships between tokens. When a user sends a prompt, the model processes the provided context and predicts tokens to generate a response. Although large language models contain significant knowledge from training, they do not automatically have access to private company documents, newly created information, or external databases.

Retrieval-Augmented Generation helps solve this limitation by allowing an application to retrieve external information before asking a language model to generate an answer. Documents can first be divided into smaller chunks, and each chunk can be converted into an embedding. An embedding is a numerical vector representing semantic meaning. These vectors can be stored in a vector database. When a user asks a question, the question is also converted into an embedding and compared with the stored vectors. The most similar chunks can then be retrieved and provided to the language model as additional context.

Chunking is therefore an important part of many RAG systems. If chunks are extremely large, they may contain several unrelated topics and produce less focused embeddings. If chunks are extremely small, important context may be separated across multiple chunks. Chunk overlap can help preserve some information between neighboring chunks. Different applications require different chunk sizes because document structure and user questions vary. Legal documents, technical documentation, FAQs, research papers, and product descriptions may all benefit from different chunking strategies.

Recursive text splitting attempts to preserve natural text boundaries while keeping chunks within a desired size. Instead of immediately cutting text at an exact character position, a recursive splitter can first try paragraph boundaries. If a piece is still too large, it can try smaller boundaries such as new lines, spaces between words, and eventually individual characters. This approach generally produces more readable and meaningful chunks than blindly splitting text every fixed number of characters.
